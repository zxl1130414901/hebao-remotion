# 贺报视频生成系统（hebao-remotion）

基于 [Remotion](https://www.remotion.dev/) 的竖屏（1080×1920 / 60fps / 约 8 秒）业绩贺报视频生成系统，内置 **200 套模板**，覆盖保险开门红、MDRT、季度/年度表彰、团队战报、晋升喜报等场景。

## 仓库内容

| 目录 | 说明 |
|---|---|
| `hebao-remotion/` | 工程源码：43+ 套版式骨架、出片台（studio）、画廊构建脚本、基准测试 |
| `贺报-通用版-200/` | 200 支成片 + 画廊 gallery.html + 总览图 + previews 缩略图 + 使用说明 |
| `贺报-通用版-115/`、`贺报-通用版-65/` | 历史批次交付存档 |
| `贺报输出/` | 示例输出 |
| `*.mp4` | 单套主题版样片（泰康养老、红金版、榜单风云版等） |

## 快速开始

```bash
cd hebao-remotion
npm install
npm run make          # 批量渲染
npm start             # 打开 Remotion Studio 预览
```

Windows 用户可直接运行 `启动出片台.bat`（在交付目录中），自动安装依赖、启动出片台并打开浏览器。

详见 `贺报-通用版-200/使用说明.md`（含画廊浏览、改字出片、常见问题排查表）。
